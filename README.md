# ConectaCruz

Express GO es el caso de negocio de esta actividad. Propone pedidos de comida de madrugada en Santa Cruz de la Sierra. ConectaCruz es el prototipo Flutter de la consigna y demuestra la bienvenida y la navegación inicial en Android.

## Código fuente

El proyecto está en la raíz del repositorio. La bienvenida de la actividad se encuentra en `BienvenidaPage`, dentro de [lib/main.dart](lib/main.dart). Al pulsar «Ver negocios», se abre el catálogo con seis negocios de demostración. La acción Atrás vuelve a la bienvenida.
